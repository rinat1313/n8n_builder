# Анализ рынка и позиционирование кандидата (АСУ ТП / нефтегаз)

Дата обзора: ноябрь 2026. Источники — актуальные вакансии hh.ru и отраслевые площадки (Газпром нефть, Экситон, МПЦ Инжиниринг, ВАЗСИСТЕМ, Техномир и др.).

---

## Что сейчас ищут работодатели

### Обязательный «ядро» вакансий нефтегаз / АСУ ТП

| Требование | Частота | У вас | Комментарий |
|---|---|---|---|
| WinCC OA / КАСКАД | Очень высокая | ✅ Сильный match | Главный «магнит» резюме |
| АльфаПлатформа / Регул | Высокая (импортозамещение) | ✅ Сильный match | Часто «приветствуется» → у вас уже опыт + сертификат |
| ПЛК + МЭК 61131-3 | Обязательно | ✅ Есть | Формулировать именно как «МЭК 61131-3» |
| Modbus RTU/TCP, OPC UA | Обязательно | ✅ Есть | Писать оба протокола явно |
| ПНР на объекте | Обязательно / почти всегда | ✅ Есть + Север | Крайний Север / Обская губа — сильный плюс для нефтянки |
| Техническая документация | Обязательно | ✅ Есть | Инструкции, отчёты, тесты ПЛК |
| Командировки / вахта | Часто | ✅ Готов | Писать прямо в шапке и в «О себе» |
| Linux + SQL/PostgreSQL | Часто | ✅ Есть | PostgreSQL Pro — преимущество |
| C++ для расширения SCADA | Часто у WinCC OA / КАСКАД | ✅ Есть | Модули на C++ — редкий и дорогой навык |
| Готовность обучать / вести младших | У ведущих позиций | ✅ Готов | Заявлять готовность к тимлиду |

### Что даёт преимущество над «средним» кандидатом

1. **Связка WinCC OA + C++ модули** — редкая комбинация; прямо встречается в вакансиях разработчиков КАСКАД.
2. **Регул + АльфаПлатформа + сертификат** — попадание в импортозамещение (МПЦ, Техномир, КСТ и др.).
3. **ПНР на Крайнем Севере (нефтегаз)** — для Газпром нефти / подрядчиков ЯНАО–ХМАО это прямой опыт среды.
4. **Инфраструктура:** Docker, Hyper-V, PostgreSQL Pro, подготовка к ИБ — закрывает «полный цикл» интегратора, а не только мнемосхемы.
5. **Go + инструменты для команды** — на рынке АСУ ТП почти не встречается; выделяет как инженера, который умеет ускорять разработку (тимлид-профиль).
6. **Allen-Bradley** — плюс для объектов со смешанным парком оборудования.

### Чего в требованиях много, а у вас пока слабо / не указано

| Пробел | Насколько критично | Что делать |
|---|---|---|
| Siemens TIA Portal / Step7 / S7 | Высоко для части нефтянки (Газпром нефть и др.) | Не выдумывать опыт. Либо быстрый курс + pet-проект, либо в сопроводительном: «готов освоить TIA Portal, есть база МЭК 61131-3 и опыт Allen-Bradley/Регул» |
| Wonderware / InTouch | Средне | Не акцентировать |
| Английский (чтение техдоков) | Часто «обязательно» | Указать хотя бы Reading / A2–B1 tech |
| ГОСТ 21/34, ПУЭ, HAZOP | Для ведущих инженерных ролей | Добавить, если реально сталкивались; иначе изучить базово |
| Количественные метрики проектов | Важно для hh | Добавить: число точек I/O, объектов, АРМ, длительность ПНР — как только вспомните цифры |

## Рекомендуемое позиционирование

**Не** «просто наладчик» и **не** «чистый программист без поля».

**Да:**  
**«Инженер-программист / интегратор АСУ ТП полного цикла: ПЛК → SCADA (WinCC OA) → сервера/СУБД → ПНР → ИБ, с сильной разработкой на C++/Go».**

Это закрывает три типа вакансий сразу:
1. Инженер-программист АСУ ТП (нефтегаз, командировки) — 140–300k+  
2. Разработчик WinCC OA / КАСКАД (офис + редкие выезды)  
3. Ведущий / тимлид разработки АСУ ТП (после 3+ лет опыта — у вас уже ~3+ года к 2026)

## Стратегия откликов

1. **Приоритет A (максимальный match):** WinCC OA / КАСКАД + C++, АльфаПлатформа/Регул, ПНР нефтегаз.  
2. **Приоритет B:** вахтовые инженеры АСУ ТП ЯНАО/ХМАО с SCADA + ПЛК (даже если в требованиях Siemens — откликаться с письмом).  
3. **Приоритет C:** позиции тимлида / ведущего инженера-программиста АСУ ТП — подчёркивать инструменты на Go и опыт ведения разработки.  
4. На каждую вакансию A/B — короткое сопроводительное (шаблон в `RESUME_HH.md`), подставить 1–2 навыка из текста вакансии.  
5. В резюме на hh.ru включите «готов к переезду / вахте / командировкам» — иначе северные вакансии вас отфильтруют.

## Что усилить в ближайшие 1–2 месяца (чтобы стать «лакомым»)

1. **Цифры в резюме** — объекты, точки, срок ПНР, сколько человек в команде.  
2. **TIA Portal / Siemens** — хотя бы базовый уровень (самый частый gap vs нефтянка).  
3. **Портфолио без NDA:** скриншоты архитектуры (обезличенные), описание модуля C++ для WinCC OA, пример CLI/UI-инструмента на Go.  
4. **ИБ / КИИ** — если готовили систему к ИБ, сформулировать конкретнее (политики, сегментация, журналирование, обновления).  
5. **Английский техдок** — одна строка в резюме сильно повышает проходимость ATS/HR.
