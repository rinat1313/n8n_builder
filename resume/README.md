# Резюме АСУ ТП для HeadHunter

Пакет материалов для трудоустройства инженером-программистом / интегратором АСУ ТП (нефтегаз, промышленная автоматизация).

| Файл | Назначение |
|---|---|
| `RESUME_HH.md` | Полное резюме + шаблон сопроводительного письма |
| `HH_COPY_PASTE.txt` | Тексты для прямой вставки в поля hh.ru |
| `MARKET_ANALYSIS.md` | Разбор рынка вакансий и стратегия позиционирования |

## Как пользоваться

1. Откройте `HH_COPY_PASTE.txt`.
2. Заполните поля в `[квадратных скобках]`: ФИО, контакты, юр. название «Сибком», образование, английский, зарплата.
3. Перенесите блоки в профиль на [hh.ru](https://hh.ru).
4. Перед откликом прочитайте `MARKET_ANALYSIS.md` и подстройте 1–2 формулировки под текст вакансии.
5. К каждому отклику на приоритетные вакансии прикладывайте сопроводительное письмо из шаблона.

## Целевые роли

- Ведущий инженер-программист АСУ ТП  
- Инженер-программист WinCC OA / КАСКАД  
- Инженер АСУ ТП (ПНР, нефтегаз, вахта)  
- Интегратор / тимлид разработки промышленных систем (C++ / Go)
