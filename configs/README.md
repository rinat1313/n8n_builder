# configs

Здесь хранятся **конфигурации для загрузки в n8n** (файлы экспорта / импорта).

## Структура

```text
configs/<имя-проекта>/
```

Внутри — готовые JSON (или иные) файлы экспорта workflow/credentials-шаблонов, которые можно импортировать в n8n.

## Правила

1. Имя папки = имя проекта (как в `projects/` и `description/`).
2. Сюда попадают только конфигурации после разработки исполнителем и проверки тестировщиком.
3. Черновики и промежуточные варианты держать в `projects/<имя>/`, пока тесты не пройдены.
4. Один проект — свои изолированные файлы; не переиспользовать чужие конфиги без явной копии и пометки.
