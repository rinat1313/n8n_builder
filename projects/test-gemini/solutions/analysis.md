# Анализ требований (analyst)

## In scope

- Telegram → Gemini 3.1 Flash → Telegram, текст как есть.
- История диалога на пользователя (chat).
- Доступ только владельцу (chat id).
- Только текстовые сообщения.
- Дробление длинных ответов.
- Сохранение логов.

## Out of scope

- Создание бота в BotFather (делает пользователь).
- Голос/фото/стикеры.
- Команды бота.
- Vertex AI.

## Критерии приёмки

1. Текст пользователя уходит в `contents` без перефразирования.
2. В Telegram уходит только текст модели (чанки без префиксов).
3. Не-текст и чужие chat id молча игнорируются.
4. Повторные сообщения в том же чате видят историю.
5. Логи раундов пишутся в static data workflow.
