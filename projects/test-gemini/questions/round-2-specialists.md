# Раунд 2 — специалисты после ответов

## Вердикт

**Новых вопросов к пользователю нет.** Блокеры закрыты ответами или явным «настрою сам».

## Допущения (зафиксировать в решении)

1. `ALLOWED_CHAT_ID` — плейсхолдер `CHANGE_ME_CHAT_ID`; пользователь подставит свой Telegram chat id.
2. Telegram Bot API credential и Google AI Studio API key — пустые/плейсхолдеры в экспорте; пользователь привяжет на self-hosted n8n.
3. История + логи: встроенное static data workflow (история по chatId) + append-only лог в файл через ноду Write Binary File / Code (путь настраивается, по умолчанию `/data/test-gemini-log.jsonl` с пометкой «поменять под свой volume»).
4. Модель API: `gemini-3.1-flash` как указал пользователь; при 404 на стороне Google — сменить id в Set-ноде.
5. Команды игнорируются как текст (уходят в Gemini как есть) — отдельной обработки `/start` нет, по ответу «только текст».
