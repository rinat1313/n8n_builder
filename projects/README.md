# projects

Здесь хранятся **данные по проектам**. Проекты друг с другом не пересекаются.

## Структура

```text
projects/<имя-проекта>/
```

Внутри папки проекта — всё, что относится именно к нему: цели, полное описание работы, заметки, ответы пользователя, решения специалистов, отчёты planner и прочая внутренняя информация.

## Правила

1. Одна папка = один проект. Не смешивать материалы разных проектов.
2. Имя папки совпадает с именем проекта (slug: латиница, цифры, `-`).
3. Сюда пишут агенты и planner; пользователь обычно читает краткую версию в `description/`.
4. Перед началом работы planner обязан проверить, есть ли уже папка проекта.
