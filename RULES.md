# Правила хранилища n8n_builder

Три корневые папки. В каждой — подпапки с **именем проекта**. Проекты изолированы и не пересекаются.

| Папка | Назначение |
| --- | --- |
| `projects/<проект>/` | Внутренние данные проекта: ТЗ, ответы пользователя, анализ, решения, отчёты |
| `description/<проект>/` | Краткое пользовательское описание, инструкция, проблемы, важная информация |
| `configs/<проект>/` | Готовые файлы экспорта для импорта в n8n |

## Именование проекта

- Если в ТЗ есть название — использовать его (нормализовать в slug: `my-project`).
- Если названия нет — придумать короткое имя по функционалу и зафиксировать в `projects/<имя>/`.

## Изоляция

- Не читать и не писать файлы чужого проекта без явной задачи на миграцию/сравнение.
- Перед работой всегда сверять наличие папки в `projects/`.
