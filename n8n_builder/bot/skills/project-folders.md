# Правила папок проекта

Корневое хранилище (cwd репозитория):

| Путь | Содержимое |
| --- | --- |
| `projects/<проект>/` | Всё по проекту: ТЗ, ответы, анализ, решения, внутренние отчёты |
| `description/<проект>/` | Краткое описание для пользователя, инструкция, проблемы |
| `configs/<проект>/` | Готовые файлы экспорта для импорта в n8n |

## Обязательные правила

1. Проекты **не пересекаются**. Работа только внутри папок своего `<проект>`.
2. Имя папки одинаково во всех трёх каталогах.
3. Если в ТЗ нет названия — придумать slug по функционалу и сохранить в `projects/<проект>/meta.md`.
4. Перед стартом проверить `projects/<проект>/` через инструменты `list_projects` / `get_project_context` / `ensure_project`.
5. В `configs/` класть только проверенные экспорты; черновики — в `projects/`.
6. В `description/` писать только после успешных тестов (фаза писателя).

Подробности: корневой файл `RULES.md` и README в каждой папке.
