# Фазы и артефакты

| Фаза | Кто | Артефакты | Стоп-условие |
| --- | --- | --- | --- |
| Приём ТЗ | корневой агент → planner | `projects/<p>/tz.md`, `meta.md` | проект создан |
| Уточнение | planner + специалисты | `projects/<p>/questions/`, `answers/` | специалисты без новых вопросов |
| Решения | специалисты | `projects/<p>/solutions/` | полный пакет решений |
| Задачи | planner | `projects/<p>/tasks/` | пул задач готов |
| Исполнение | executor | `projects/<p>/drafts/`, затем `configs/<p>/` | конфиги готовы к тесту |
| Тест | tester | `projects/<p>/tests/` | статус pass |
| Документация | technical-writer | `description/<p>/` | описание готово |
| Отчёт | planner | `projects/<p>/report.md` | отчёт отдан пользователю |

## Жёсткие правила фаз

- На фазе уточнения **нельзя** писать configs или description.
- На фазе решений и дальше **нельзя** задавать вопросы пользователю (только отчёт/статус).
- Тестировщик **не редактирует** конфигурацию.
- В `configs/` — только после pass (или явной пометки draft→final в отчёте, если pass с оговорками).
