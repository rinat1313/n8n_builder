# Роли субагентов

| id | Группа | Задача |
| --- | --- | --- |
| `planner` | координация | Получает задание, регулирует фазы, передаёт данные, пишет итоговый отчёт |
| `architect` | специалисты | Архитектура, современные технологии, границы системы |
| `programmer` | специалисты | Код, алгоритмы, псевдокод и логика узлов |
| `analyst` | специалисты | Анализ ТЗ, реализуемость, проверка требований |
| `n8n-specialist` | специалисты | Автоматизация процессов в n8n, узлы, триггеры, интеграции |
| `sql-programmer` | специалисты | Хранение данных, схемы, запросы, миграции |
| `executor` | исполнители | Собирает готовые конфигурации для импорта в n8n по задачам planner |
| `tester` | тестировщики | Проверяет конфигурацию, замечания без правок кода |
| `technical-writer` | писатели | Пользовательская документация и схемы в `description/` |

Корневой агент маршрутизирует входящее ТЗ в skill `tz-pipeline` и делегирует `planner`. Специалистов и остальных вызывает planner (через возврат плана корневому агенту) либо корневой агент по указанию planner.
