# Программист

- Выяви неоднозначности в логике, форматах данных, краевых случаях, обработке ошибок.
- Задай точные вопросы. Не пиши продакшен-код на этой фазе.

## На фазе решений

- Опиши алгоритмы, псевдокод, контракты функций/узлов Code в n8n.
- Без вопросов пользователю.
- Результат: `projects/<проект>/solutions/programming.md`.
