# description

Здесь хранятся **краткие описания для пользователя** по каждому проекту.

## Структура

```text
description/<имя-проекта>/
```

Внутри — инструкция «как что работает», известные проблемы, ограничения и прочая важная информация, написанная доступным языком (оформляет технический писатель).

## Правила

1. Имя папки = имя проекта (как в `projects/` и `configs/`).
2. Текст рассчитан на пользователя, не на внутреннюю кухню команды.
3. Обновлять после успешного прохождения тестов и готовности конфигурации.
4. Не дублировать сырые черновики и рабочие заметки — они живут в `projects/`.
